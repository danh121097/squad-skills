# Weekly reports

Store one sanitized report per completed weekly review as `YYYY-MM-DD.md`.

Record the inputs reviewed, duplicate grouping, verified findings, what was
chosen, what was deferred and why, and any unresolved evidence. Do not copy raw
private artifacts into these reports.

A week with nothing new still gets a file: one line saying so. An omitted week is
indistinguishable from a week nobody read.
